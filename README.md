# Attendance Management System (AMS) - LOGRO Showroom



## Overview



The Attendance Management System (AMS) is a web-based application developed for LOGRO Showroom to simplify employee attendance tracking and management.



The system provides a centralized platform for recording attendance, managing staff information, and monitoring attendance activities efficiently.



---



## Features



### Staff Management



* Add and manage employee records

* Maintain staff information

* Employee attendance tracking



### QR Code Attendance



* QR code-based check-in system

* Fast attendance recording

* Reduced manual attendance errors



### Attendance Monitoring



* Real-time attendance logging

* Attendance history tracking

* Daily attendance management



### Authentication



* Secure login system

## Installation



### Clone Repository



```bash

git clone git@github.com:nizx00hex/Attendance-Management-System---LOGRO.git

cd Attendance-Management-System---LOGRO

```



### Install Dependencies



```bash

composer install

```



### Configure Database



1. Create a MySQL database.

2. Import the required database schema.

3. Update database credentials in `config.php`.



### Run Application



Place the project inside your web server directory:



```text

/var/www/html/

```



Start Apache and MySQL services and access:



```text

http://localhost/AMS

```
